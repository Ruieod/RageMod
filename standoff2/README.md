# RageMod · Standoff 2 (без рута)

Нативная библиотека + dex-оверлей, которые вшиваются в APK игры. Рута не нужно: патчится сам APK, ставится как обычное приложение.

## что умеет

| | |
|---|---|
| **Aimbot** | Smooth / Snap / **Silent flick** (довод → выстрел → возврат взгляда). FOV, сглаживание, хитбокс (голова / шея / грудь / таз / ближайший / голова→тело), только видимые, пропуск тиммейтов, приоритет цели |
| **Autofire** | реакция 0 мс, Hold / Tap, пауза между тапами, допуск попадания, только видимые |
| **Recoil control** | гасит измеренный «подброс» камеры, отдельно X / Y, сила тяги |
| **Weapons** | профиль на каждое оружие (24 шт.): FOV, сглаживание, хитбокс, autofire, RCS. Оружие определяется по имени модели в руках, либо выбирается вручную |
| **Backtrack** | история позиций врагов, призрак на ESP, опционально наводка на старую запись |
| **ESP** | box (full / corners) + заливка, скелет, голова, дистанция, оружие, snaplines, стрелки за экраном, призрак backtrack, цвета видим / за стеной / тиммейт |
| **Chams** | перекраска персонажей сквозь стены (Flat / Ghost), отдельный цвет для видимых и скрытых |
| **World** | no flashbang, no smoke (2D + 3D), no stun |
| **Kill FX** | Burst / Rings / Lightning / Skull + «+1 KILL», вспышка экрана, тактильный отклик |
| **GUI** | меню в стиле Neverlose: сайдбар, карточки, слайдеры, color picker, плавающая кнопка, вотермарка (logo · user · fps · time), конфиг-слоты 1-5, экспорт / импорт через буфер |

## как работает (коротко)

* **Игра не трогается на уровне обфусцированного ядра.** Ремастер на ECS, ядро обфусцировано, поэтому всё идёт через читаемый слой Unity: `CharacterBindings`, `BipedMap`, `TeamSpawnZone`, `GrenadeBlindEffectView`, `SmokeEffectModifiersView` + обычные `UnityEngine.*`. Имена резолвятся в рантайме через il2cpp API, RVA нигде нет.
* **Тик** — подмена `MethodInfo::methodPointer` у `EventSystem.Update` / `ScrollRect.LateUpdate` (Unity сам вызывает их каждый кадр). Хуков в код игры нет.
* **Аим и автофаер — синтетические пальцы.** Оверлей оборачивает `Window.Callback` и подмешивает в поток касаний два «пальца»: look (свайп по зоне прицела) и fire (на кнопке огня). Контур замкнут по пикселям экрана: чувствительность, акселерация и инверсия Y оценивает сам (`H_GAIN` в debug-панели), поэтому подгонять ничего не надо.
* **Загрузка:** `libragemod.so` добавляется как `DT_NEEDED` в `libmain.so` (LIEF) → линкер грузит её до кода игры. `classes.dex` кладётся как следующий `classesN.dex`.

## как получить APK

1. Залей оригинальный APK (arm64) куда-нибудь, откуда есть **прямая ссылка** (например, Release-asset в этом репо). Подходит `.apk`, `.xapk`, `.apks`.
2. GitHub → **Actions → Standoff 2 mod → Run workflow**, в `apk_url` вставь ссылку.
3. В конце в артефактах будет `ragemod-patched-game`. Скачай, **удали оригинальную игру** (подпись другая) и поставь патченную. Для `.xapk` / `.apks` ставить через SAI.

Без `apk_url` workflow просто собирает `ragemod-payload` (`libragemod.so` + `classes.dex`) и `ragemod-ui-previews` (PNG меню, ESP и эффектов).

Локально (если есть ПК с SDK/NDK):

```bash
tools/test_host.sh            # тесты: аим-контур, роутер касаний, весь игровой слой на моке Unity
tools/build_native.sh         # build/out/lib/arm64-v8a/libragemod.so
tools/build_dex.sh            # build/out/classes.dex
python3 tools/patch_apk.py --lib build/out/lib/arm64-v8a/libragemod.so --dex build/out/classes.dex --out patched game.apk
```

## первый запуск

1. Плавающая кнопка **R** слева открывает меню (перетаскивается).
2. **Misc → Calibration mode**: перетащи маркер **FIRE** на свою кнопку огня, **LOOK** — на свободное место справа (не на кнопку). Жми Done. Без этого аим / автофаер не знают, куда «нажимать».
3. Включай нужное. Для проверки: **Misc → Show debug panel**.

## если что-то не работает

Debug-панель (Misc) и вкладка Config → Diagnostics показывают состояние:

* `tick hooks: 0` → хук тика не сработал (Unity не вызывает подменённый метод). Нужен inline-хук, пришли лог.
* `resolved … failed` + `missing:` → имя класса / метода изменилось после патча игры. Проверка по дампу: `python3 tools/check_dump.py dump.cs` (подсвечивает, чего нет). Имена лежат в `native/src/game.cpp`, `visuals.cpp`, `unity.cpp`.
* `characters: 0` в матче → источник персонажей другой. Пришли строку `game:` из лога.
* **Config → Copy log** копирует статус + лог в буфер.

## что не проверено / ограничения (честно)

* **На устройстве не запускалось.** У меня не было ни APK, ни телефона. Проверено: сборка (NDK + dex), все имена классов / методов / полей против твоего дампа (`check_dump.py`: 0 пропущенных), логика на хосте (аим-контур, роутер касаний, весь игровой слой на моке Unity, 46 проверок), LIEF-патч грузится aarch64-загрузчиком (qemu), APK подписывается и проходит `apksigner verify` / `zipalign -c`.
* **Здоровье и имена игроков недоступны** с Unity-слоя (они в ECS). ESP без HP-бара.
* **Команды** определяются по спавн-зонам (`TeamSpawnZone`): игрок, замеченный у спавна и стоящий на месте, получает его сторону. Если зашёл посреди раунда, пока команда неизвестна — считается врагом.
* **Silent flick — это быстрый доворот и возврат**, не серверный silent: сервер авторитарный, подмены угла в команде без доступа к ядру нет. Выстрел идёт, пока вид наведён, потом вид возвращается.
* **Backtrack — клиентский**: история позиций, призрак, наводка на старую запись. Тик-бэктрек на сервере (подмена времени в команде) из дампа не достать.
* Если у игры есть проверка подписи / целостности APK, патченый билд может не пустить в матч. Бан-риск есть всегда: играть на альт-аккаунте.
